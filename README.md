# 담을자리 – 사진으로 만드는 기억의 궁전

기억을 궁전 곳곳에 담습니다. 매일 걷는 곳을 사진으로 찍어 궁전을 짓고, 외울 것을 자리마다 담아 떠올리는 장소법(기억의 궁전) 연습 앱입니다.

- 설치형 웹앱(PWA)이며, 오프라인에서도 작동합니다.
- 데이터는 사용자의 기기에만 저장됩니다.

## 폴더
- `index.html`, `sw.js`, `manifest.webmanifest`, `icons/`: 배포되는 앱
- `src/app.html`: 앱 원본, `src/build.py`: 배포 파일 만들기 (`python3 src/build.py`)
